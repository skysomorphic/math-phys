# math-phys

this is my directory for anything latex related for my studies in mathematics and physics. this includes formal lecture notes, any assignments that ive typed up, as well as anything self-studied.

my general workflow for lectures with lots of symbols (math and physics) is to take notes on paper (or perhaps only a little or none at all if the subject demands all of my attention, or if the lecturer has provided their own notes). then, i type up my notes into latex, which doubles as a review of the concepts.

i have attempted before to live type latex for notetaking before (of course using snippets to speed things up), but ive reached the conclusion that pencil and paper is still the best way to go, especially with the ease of drawing figures and writing annotations.

my typed up lecture notes are pretty much 1:1 to what i've written down, mostly unedited.

expect some silliness and shitposting.
